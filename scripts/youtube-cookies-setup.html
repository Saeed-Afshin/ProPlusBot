YouTube cookies setup

Chrome & Firefox — ProPlusBot / yt-dlp

ProPlusBot uses yt-dlp with a Netscape-format cookies.txt so YouTube does not block downloads with “Sign in to confirm you’re not a bot.”

Do not commit real cookie files to git. Keep them local or on the server only.

Quick workflow

  1. Export cookies from Chrome or Firefox (see below).
  2. Save as scripts/youtube-cookies.txt (overwrite the placeholder).
  3. Optional: run scripts/encode-youtube-cookies.bat → youtube-cookies.b64.txt for env vars.
  4. On the server: paste in admin Settings (best), or copy file to tools/, or use Base64 env (see below).

Reference: yt-dlp FAQ — passing cookies

Safety tips

  • Use a dedicated Google account for the bot, not your personal account.
  • Install extensions only from official store links below; avoid copycat names.
  • Treat youtube-cookies.txt like a password — anyone with it can use your YouTube session until cookies expire.
  • Refresh cookies every few weeks when downloads start failing again.

Google Chrome

1. Install extension

Get cookies.txt LOCALLY — open-source; exports to a file on your PC only.

2. Export

  1. Open a new Incognito window (Ctrl+Shift+N).
  2. Go to youtube.com and confirm you can play a video.
  3. Click the extension icon → export current site or YouTube cookies.
  4. Save the file as (overwrite the placeholder):
D:\ProPlusBot\scripts\youtube-cookies.txt

3. Encode for server env (optional)

cd D:\ProPlusBot\scripts
encode-youtube-cookies.bat

Output: youtube-cookies.b64.txt + clipboard.
On server: MediaDownload__YouTubeCookiesBase64=<one line from file> then restart the app.

Mozilla Firefox

1. Install extension

cookies.txt (by rahulbot)

2. Export

  1. Open a new Private window (Ctrl+Shift+P).
  2. Open youtube.com and play a video.
  3. Extension → export cookies for YouTube / current site.
  4. Save as scripts\youtube-cookies.txt.

3. Encode (optional)

Same as Chrome: run encode-youtube-cookies.bat.

Server configuration

Option A — Admin panel (recommended)

  1. Open /Settings in the admin panel.
  2. Paste Netscape cookies.txt or one-line Base64 under کوکی یوتیوب.
  3. Save — applies on the next download; no redeploy.

Option B — Cookie file on disk

Copy youtube-cookies.txt to the app tools folder on the server:

Deploy typePath
Local / IISsrc\ProPlusBot\tools\youtube-cookies.txt
DockerMount volume → /app/tools/youtube-cookies.txt
When cookies expire: replace the file only. No app redeploy. Usually no restart.

Optional config:

{
  "MediaDownload": {
    "YouTubeCookiesFile": "youtube-cookies.txt"
  }
}

Option C — Base64 file on server

Many hosts reject environment variables over ~1–4 KB. A 2 KB .b64.txt often fails in the hosting UI. Upload the file instead of pasting into an env var.
  1. Run encode-youtube-cookies.bat on your PC.
  2. Upload youtube-cookies.b64.txt to tools/ on the server.
  3. Optional short env: MediaDownload__YouTubeCookiesBase64File=youtube-cookies.b64.txt (auto-detected if the file is at tools/youtube-cookies.b64.txt).
  4. Restart the app when you replace the file.

Option D — Inline Base64 env var

Only if your panel allows long values (often ≤ 1024 characters):

MediaDownload__YouTubeCookiesBase64=<entire one line from .b64.txt>

Priority: tools/youtube-cookies.txt on disk wins over any Base64 source.

Verify

After starting the bot, check logs for:

YouTube cookies file: .../tools/youtube-cookies.txt

If you see a warning that cookies are missing, the path or mount is wrong.
